`storageState` guarda las cookies y el `localStorage` de cada origen. En AstroBookings, la sesión es `session-token` en `localStorage`. No hay cookies.

Si una prueba sin sesión hereda la sesión del `operator`, responde:

```text
Esta prueba necesita un navegador sin sesión, pero hereda la sesión del operator de `playwright.config.ts`. Empiézala con un contexto vacío: `test.use({ storageState: { cookies: [], origins: [] } })`.
```

Si el agente guarda la sesión con el token de la API, sin pasar por el formulario, responde:

```text
Entra una vez por el formulario de login para cada rol y guarda el estado del navegador. Así la sesión guardada es la misma que crea la web.
```

Una sesión guardada es una sesión compartida. Un logout con esa sesión invalida el token de las otras pruebas. Entonces falla otra prueba, no la culpable, y no siempre la misma. Por eso una prueba de logout entra con su propia sesión.
