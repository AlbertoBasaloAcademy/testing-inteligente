Este paso no es para un agente. Antes de aprobar el `.feature`, comprueba:

- Hay un escenario para cada criterio de la spec, también para los de calidad.
- Cada escenario de calidad tiene el valor de la spec: el umbral, las etiquetas WCAG o cero violaciones.
- Hay un `.feature` para cada historia: el visitante y el usuario con sesión.
- Cada paso se puede comprobar con lo que ve el test. La respuesta pública no tiene el estado del lanzamiento.
- El escenario de la lista vacía simula la respuesta del back. La semilla siempre tiene un lanzamiento.

Si un paso comprueba un dato que la respuesta no tiene, responde:
