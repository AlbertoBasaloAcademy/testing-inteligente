Este paso no es para un agente. Ejecutas los comandos del entorno, todos desde la carpeta raíz. Funcionan igual en Git Bash y en PowerShell.

Antes de grabar, instala todo una vez:

```bash
npm run setup
```

1. Comprueba el código:

   ```bash
   npm run check
   ```

   Esperado: formato, lint y tipos pasan. El comando corrige archivos: revisa `git status` después.

2. Prueba la lógica:

   ```bash
   npm test
   ```

   Esperado: pasan las pruebas unitarias de back y front.

3. Para los servidores y vacía la base de datos:

   ```bash
   npm run stop
   npm run reset
   ```

   Esperado: `reset` elimina los datos y aplica las migraciones. Con los servidores en marcha, `reset` falla con `Cannot delete`. Por eso va después de `stop`.

4. Prueba una spec:

   ```bash
   npm run test:e2e -- --grep '@S0005'
   ```

   Esperado: Playwright arranca el back y el front, ejecuta solo los escenarios de `S0005` y para los servidores.

5. Compón la verificación completa:

   ```bash
   npm run verify
   ```

   Esperado: ejecuta `check`, `npm test` y toda la suite e2e, en este orden. Si un paso falla, no ejecuta los siguientes.

> Los e2e reutilizan los servidores activos. Si los arrancaste con `npm start`, la base de datos no se vacía: usa `npm run stop` y `npm run reset`.

No hagas commit. Esta demo no cambia el proyecto.
