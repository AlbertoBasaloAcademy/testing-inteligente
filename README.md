## Empezar el curso

Clona el repositorio desde el que consultas este índice. Entra en la carpeta del proyecto y ejecuta:

```bash
git switch inicial
npm install
npm install --prefix projects/back
npm install --prefix projects/front
npm start
```

- Front: <http://localhost:4000>.
- Back: <http://localhost:3000>.

Para consultar una lección o el resultado final:

```bash
git switch M01-L01
git switch final
```

Ejecuta solo el comando de la rama que necesitas. Guarda tus cambios antes de cambiar de rama. Consulta el README de esa rama para instalar y ejecutar su versión.

Los enlaces del índice son relativos al repositorio y permiten usar este README en los dos repositorios del curso.
